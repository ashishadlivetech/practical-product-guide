PRACTICAL PRODUCT GUIDE — CONTENT UPDATE

UPLOAD:
1. Extract this ZIP.
2. Open the existing GitHub repository.
3. Use Add file > Upload files.
4. Upload the updated root index.html and the complete guides folder contents.
5. GitHub will show that index.html is being replaced; this is intentional.
6. Commit changes to main.
7. Wait for GitHub Pages to rebuild, then check:
   https://ashishadlivetech.github.io/practical-product-guide/

IMPORTANT:
- Do not delete the existing three original guide files in guides/.

- The source links are official manufacturer pages and technical/support documentation where possible.
